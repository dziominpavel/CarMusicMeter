# Spec Delta — playback-capture

## ADDED Requirements

### Requirement: Финализация открытого прослушивания при старте службы

При старте службы приложение MUST закрыть прослушивание, оставшееся открытым от
предыдущего процесса, ровно одним `track_ended` с причиной `session_lost` и MUST
сделать это до первого нового `track_started`. Для `playedMs` MUST
использоваться последняя сохранённая контрольная точка этого прослушивания; если
контрольной точки нет — `playedMs = 0`, а `rawPlayedMs` совпадает с ним.
Закрытие MUST NOT создавать новое прослушивание само по себе.

#### Scenario: Зажигание выключили в середине трека

- **WHEN** магнитола выключилась во время трека, а на следующей загрузке служба
  стартовала и плеер снова играет
- **THEN** в журнале есть `track_ended(session_lost)` для прошлого прослушивания
  и только после него — новый `track_started`

#### Scenario: Обновление APK во время трека

- **WHEN** пакет заменили, пока трек играл, и новый процесс начал сбор
- **THEN** прошлое прослушивание закрыто одним `track_ended`, а новый
  `track_started` не дублирует уже открытое

#### Scenario: Трек оборвался на паузе

- **WHEN** трек стоял на паузе с сохранённой контрольной точкой, а питание пропало
- **THEN** `track_ended` содержит `playedMs` из этой контрольной точки

#### Scenario: Служба остановлена штатно

- **WHEN** пользователь остановил службу кнопкой и она записала `track_ended`
- **THEN** при следующем старте повторного `track_ended` для этого прослушивания нет

#### Scenario: Сохранённого состояния нет

- **WHEN** служба стартовала впервые или состояние предыдущего процесса отсутствует
- **THEN** событий `track_ended` на старте не пишется
