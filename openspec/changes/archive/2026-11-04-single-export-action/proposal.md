# Proposal

## Why

На главном экране два действия для одной задачи: «Снять срез» и «Экспорт логов».
Снимок уходит в приватный каталог, пользователь видит только тост с именем файла,
и попадает на ПК лишь внутри ZIP — поэтому связь «сначала срез, потом экспорт»
приходится запоминать по инструкции в настройках. Экспорт при этом выделен как
главное действие, а «срез» остаётся непонятной кнопкой без видимого результата.

## What Changes

- **BREAKING** для UI: кнопка «Снять срез» удаляется с главного экрана. Главный
  экран оставляет одно действие — «Экспорт логов».
- Снимок состояния снимается автоматически при открытии диалога экспорта, до
  расчёта плана, поэтому свежий снимок всегда попадает в ZIP и учитывается
  в счётчике файлов.
- В диалоге экспорта вместо «N файлов · объём» показывается разбивка
  «журнал · снимки · crash» и строка о том, что свежий снимок снят только что.
- Снимок при экспорте пишется с причиной `export` вместо `manual`.
- Сбой снимка не блокирует экспорт: ошибка логируется, архив собирается.
- Состав полей снимка не меняется, автозапись на старте трека сохраняется.
- Инструкция «Проверка в машине» и документация теряют шаг со «срезом».

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `app-shell`: главный экран предоставляет только действие экспорта; требование
  о двух действиях и вторичном снимке заменяется одним действием.
- `event-log`: снимок создаётся при экспорте и на старте трека, а не «по кнопке»;
  диапазон экспорта и оценка объёма учитывают свежий снимок; диагностика UI
  штатного плеера привязана к экспорту вместо кнопки «Снять срез».
- `playback-capture`: сценарий полного дампа активных сессий привязан к экспорту
  вместо кнопки «Снять срез».

## Impact

- `ui/DashboardScreen.kt` — `DashboardActions` остаётся с одной кнопкой.
- `MainActivity.kt` — удаляется `takeSnapshot()`, снимок добавляется в поток
  открытия диалога экспорта; `SnapshotWriter` продолжает использоваться.
- `ui/ExportDialog.kt` — разбивка плана по видам файлов.
- `ui/SettingsScreen.kt`, `docs/HEADUNIT_TEST.md`, `README.md` — тексты без
  шага «снять срез».
- `data/EventLog.kt` — без изменений формата ZIP и манифеста; меняется только
  момент появления файла снимка.
- ПК-скрипты (`scripts/report.py`) причину снимка не разбирают — совместимость
  сохраняется.
