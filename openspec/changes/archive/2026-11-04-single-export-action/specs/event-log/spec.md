# Spec Delta

## MODIFIED Requirements

### Requirement: Снимок диагностики

Приложение MUST сохранять JSON-снимок при каждом экспорте и MUST сохранять снимок
автоматически при старте каждого трека. Снимок MUST содержать версию приложения,
модель устройства, версию Android, состояние доступа к уведомлениям,
состояние accessibility-доступа (системную настройку и фактическое
подключение сервиса), громкость выбранного источника, все аудиопотоки,
`isVolumeFixed`, `audioMode`, `isMusicActive`, аудиовыходы, все активные
сессии, последние уведомления с признаком `mediaLike`, состояние штатного
плеера с источником и сырыми текстами, состояние сервиса метаданных FYT,
состояние вендорного toolkit и список установленных пакетов Teyes/FYT/лаунчера.

#### Scenario: Первый трек в машине

- **WHEN** штатный плеер начал играть первый трек
- **THEN** рядом с журналом появляется снимок `snapshot-*-track_started.json`

#### Scenario: Снимок при экспорте

- **WHEN** пользователь открывает диалог экспорта
- **THEN** рядом с журналом появляется снимок `snapshot-*-export.json` с состоянием на этот момент, и он попадает в архив

#### Scenario: Громкость на Teyes

- **WHEN** приложение снимает снимок при экспорте, а громкость на панели равна 4
- **THEN** снимок содержит `teyes.volume=4`, `teyes.max=43`, `teyes.source=mcu`,
  значения и максимумы всех аудиопотоков и `isVolumeFixed`, даже если
  `STREAM_MUSIC` показывает 25/25

#### Scenario: Штатный плеер без MediaSession

- **WHEN** штатный плеер не отдаёт MediaSession
- **THEN** снимок содержит `stockPlayer` с последним известным названием,
  источником, сырыми текстами accessibility и/или `RemoteViews`, а также
  список пакетов, по которым можно проверить имя плеера

#### Scenario: Неизвестное уведомление

- **WHEN** локальный плеер публикует уведомление без медиашаблона
- **THEN** оно попадает в снимок с `mediaLike = false`, но не создаёт событие
  `notification` в журнале

#### Scenario: Сервис метаданных FYT

- **WHEN** штатный плеер прислал `com.fyt.launcher.music`
- **THEN** снимок содержит `fytMetadataService.received=true`, пакет, набор
  ключей и время последнего обновления

#### Scenario: Accessibility включена, но сервис не подключён

- **WHEN** системная настройка accessibility включена, а сервис не подключён
- **THEN** снимок содержит `accessibilityEnabled=true` и
  `accessibilityConnected=false`

### Requirement: Диагностика UI штатного плеера

Приложение MUST сохранять диагностику UI штатного плеера в снимке и в событии
`stock_player_ui` при изменении состояния или при экспорте. Диагностика
MUST содержать все видимые тексты без фильтра, для каждого узла — `className`,
`viewIdResourceName`, `text`, `contentDescription`, `rangeInfo`, а также список
окон с пакетом, заголовком, признаками `active`/`focused`. Приложение MUST
ограничивать число узлов и MUST NOT писать событие на каждом тике без изменений.
Изменение только бегущей позиции (текст времени, `rangeInfo.current`, полоса
прогресса) MUST NOT считаться изменением состояния. Пока окно плеера видно,
приложение MUST дополнительно писать `stock_player_ui` не чаще одного раза в
пять минут, даже если ничего не изменилось, чтобы в журнале было видно, что окно
доступно.

#### Scenario: Плеер в split-screen

- **WHEN** приложение снимает снимок при экспорте, а плеер виден рядом с навигатором
- **THEN** снимок содержит окно `com.syu.music`, его узлы и `rangeInfo` прогресса

#### Scenario: Переходный экран

- **WHEN** плеер открылся и первое чтение вернуло заголовок папки
- **THEN** `stock_player_ui` содержит все тексты и признак, что парсер отклонил состояние

#### Scenario: Повторный тик

- **WHEN** UI плеера не изменился с прошлого тика
- **THEN** повторное событие `stock_player_ui` не пишется

#### Scenario: Играет трек, тикает только время

- **WHEN** окно плеера открыто, трек играет, и между тиками изменилась только позиция
- **THEN** повторное событие `stock_player_ui` не пишется

#### Scenario: Сменился трек или экран

- **WHEN** в окне плеера изменились название, исполнитель или набор видимых элементов
- **THEN** появляется новое событие `stock_player_ui`

#### Scenario: Окно видно, ничего не меняется

- **WHEN** окно плеера видно двадцать минут, а трек и экран не меняются
- **THEN** за это время есть несколько событий `stock_player_ui`, но не больше
  одного за пять минут
