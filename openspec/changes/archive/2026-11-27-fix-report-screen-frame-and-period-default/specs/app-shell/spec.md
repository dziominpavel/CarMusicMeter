# Delta for app-shell

## ADDED Requirements

### Requirement: Единая рамка экрана с отступами системных панелей

Каждый экран приложения MUST накладывать отступы системных панелей через одну
общую рамку. Содержимое MUST NOT попадать под системную панель и кнопку меню
магнитолы. Отступы MUST быть одинаковыми на всех экранах, а элементы верхней
строки, включая кнопку «Назад», MUST оставаться доступными для нажатия.

#### Scenario: Кнопка «Назад» на экране отчёта

- **WHEN** пользователь открывает отчёт на магнитоле
- **THEN** верхняя строка расположена ниже системной панели, кнопка «Назад» видна и нажимается

#### Scenario: Одинаковые отступы на всех экранах

- **WHEN** пользователь переключается между пультом, настройками, диагностикой, отчётом и карточкой трека
- **THEN** содержимое начинается на одном и том же расстоянии от края экрана
