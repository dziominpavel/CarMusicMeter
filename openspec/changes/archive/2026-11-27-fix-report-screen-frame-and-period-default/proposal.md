# Proposal

## Why

На магнитоле верхняя строка экранов отчёта («Анализ», «Все треки», «Качество
данных», карточка трека) уходила под системную панель: кнопка «Назад»
оказывалась под ней и не нажималась, хотя на «Настройках» и «Диагностике» та же
кнопка работала. Причина — часть экранов не накладывала отступы системных
панелей.

Второе: отчёт открывался по умолчанию за 7 дней. После недели без поездок окно
пустеет само, и отчёт выглядит как потеря данных — так и было воспринято после
обновления, хотя факты целы.

## What Changes

- Все экраны получают одну общую рамку с отступами системных панелей
  (`safeDrawing`); верхняя строка и кнопка «Назад» больше не уходят под панель.
- Отчёт по умолчанию открывается за всю историю; явный выбор периода
  по-прежнему запоминается между запусками.
- Когда за выбранный период прослушиваний мало, отчёт и пустой список «Все
  треки» подсказывают переключить период вместо молчаливого пустого экрана.

### Modified Capabilities

- `app-shell`: добавляется требование о единой рамке экрана с отступами
  системных панелей во всех экранах.
- `listening-report`: период по умолчанию — вся история; подсказка при малом
  числе прослушиваний за выбранный период.

## Impact

- `ui/AppComponents.kt` — общий модификатор рамки; `ui/ReportScreen.kt`,
  `ui/QualityScreen.kt`, `ui/AllTracksScreen.kt`, `ui/TrackDetailScreen.kt`,
  `ui/SettingsScreen.kt`, `ui/DiagnosticsScreen.kt`, `ui/DashboardScreen.kt` —
  переход на общую рамку.
- `data/metrics/ReportPeriod.kt` — значение периода по умолчанию;
  `data/ReportRepository.kt`, `data/Prefs.kt` — согласование с ним.
- Тесты: `ReportPeriodTest` (значение по умолчанию).
- Проверка на устройстве: кнопка «Назад» и отступы на магнитоле.
