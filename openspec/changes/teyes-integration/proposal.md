# Proposal

## Why

Первый реальный ZIP с Teyes CC3 показал три разрыва:

- штатный плеер `com.yf.teyesspotify` не публикует MediaSession, а его
  уведомление приходит пустым (`title=null`, `text=null`, без `mediaLike`);
- `AudioManager.STREAM_MUSIC` постоянно показывает `25/25`, хотя на панели
  громкость 4 — реальной громкостью управляет MCU;
- в журнале нет `boot_received` и `service_started` с `source=boot`: после
  выключения зажигания приложение не поднимается само.

Дополнительно пресеты «Бессрочно / 1 год / 180 / 90 дней» и «Вся история /
90 / 30 / 7 дней» занимают по две строки — на экране магнитолы это лишняя
вертикаль.

## What Changes

- **Штатный плеер Teyes.** Добавить резервные источники данных помимо
  MediaSession:
  - broadcast `titlesReceiver` / `removeReceiver` от лаунчера FYT (если
    прошивка его отправляет);
  - текст пользовательского уведомления, включая `RemoteViews`, и все
    extras;
  - необязательный accessibility-сервис, который только читает текст
    открытого окна штатного плеера и ничего не нажимает.
  Источники сводятся в один `MediaSnapshot` с полем `source`; приоритет:
  MediaSession → broadcast → accessibility → уведомление.
- **Громкость MCU.** Подключиться к вендорному сервису `com.syu.ms`
  (`app.ToolkitService`, модуль `sound`), читать `U_VOL` и `U_MUTE` и
  фиксировать реальную громкость панели. Если сервис недоступен — прежний
  опрос `AudioManager`. В событии `volume_changed` появляется `source`.
- **Автозапуск.** Добавить persisted `JobScheduler`, реакцию на
  `MEDIA_MOUNTED`, запуск службы при открытии приложения и отдельный
  невидимый пункт «CarMusicMeter (автозапуск)» для списка автозапуска Teyes.
  Описать точный путь whitelist для прошивки.
- **Экран.** Все четыре пресета срока и все четыре периода экспорта — в одной
  строке; добавить статус источника плеера и громкости.
- **Диагностика.** В снимок добавить состояние вендорного toolkit, последнее
  состояние штатного плеера, список подходящих установленных пакетов,
  extras и `RemoteViews`-текст уведомлений, сырые тексты accessibility.

## Impact

- Спеки: `playback-capture` (новый резервный источник), `volume-tracking`
  (MCU-громкость и неизвестный максимум), `event-log` (диагностика,
  источники запуска, новые поля событий).
- Разрешения: новых опасных разрешений нет. Accessibility — отдельный
  необязательный спецдоступ, только чтение. `INTERNET` не добавляется.
- Формат JSONL остаётся совместимым: новые поля аддитивны, `schemaVersion`
  не меняется.

## Non-Goals

- Свой плеер, аудиофокус, изменение громкости, запись звука.
- Автоматические нажатия в интерфейсе плеера.
- LAN-синхронизация и встроенная статистика — отдельные changes.
