# Proposal

## Why

Экран запуска сейчас — это видеофайл (`res/raw/splash.mp4`) через `MediaPlayer`
и `TextureView`. Его тайминг задаёт декодер, а не код: на медленном старте
watchdog обрывает клип на середине, на быстром проходит полностью, поэтому
каждый запуск выглядит по-разному. Вдобавок это единственное место в приложении,
где вообще инициализируется воспроизведение, — под подозрением на короткий писк
при старте и на переключение аудиоисточника MCU.

## What Changes

- Видео-заставка заменяется сценой, которую рисует Compose поверх статичного
  арта: вдох картинки с масштабом и свечением, обегающая обод дуга и прорисовка
  волны. Рисунок и тайминг берутся из варианта `F:\carmusicmeter_intro.html`
  (композиция «Instrument Wake», 1.42 с).
- Таймлайн становится детерминированным: анимация 1.4 с → удержание 0.15 с →
  гашение 0.2 с, всего 1.75 с. Сторожевой таймер больше не режет анимацию,
  потому что резать нечего.
- **BREAKING** для внутренностей: `MediaPlayer`, `TextureView`, `Surface`,
  `HandlerThread` и сам `splash.mp4` из заставки удаляются. `drawable-nodpi/splash_still.webp`
  с вотермарком `PixVerse.ai` заменяется чистым артом без вотермарка.
- Заставка перестаёт быть единственным местом с воспроизведением: в приложении
  не остаётся ни одного вызова `MediaPlayer`/`AudioTrack`/`SoundPool`.
- Документация проверки в машине обновляется: вместо «анимация может оборваться
  на 1.8 с» — фиксированная длительность и проверка отсутствия звука.

Визуальный язык (медальон `TEYES CC3`, фиолетово-оранжевая палитра) сохраняется,
меняется только техника воспроизведения анимации.

## Capabilities

### New Capabilities

Нет: все требования экрана запуска уже принадлежат `app-shell`.

### Modified Capabilities

- `app-shell`: требования экрана запуска. «Длительность и завершение заставки»
  получает фиксированный таймлайн; «Нет чёрного кадра при проблемах с видео»
  становится неприменимым и удаляется; добавляется требование о том, что заставка
  не воспроизводит медиа и не открывает аудиотракт.

## Impact

- `app/src/main/java/com/example/carmusicmeter/ui/LaunchSplash.kt` — переписывается
  целиком.
- Новый чистый модуль таймлайна в `data/` с JVM-тестами.
- Ресурсы: удаляются `res/raw/splash.mp4` (256 КБ) и `res/drawable-nodpi/splash_still.webp`
  (33 КБ), добавляется `res/drawable-nodpi/splash_art.webp` (~40-80 КБ).
  Итог по APK — минус ~200-250 КБ.
- `docs/HEADUNIT_TEST.md` — сценарий проверки заставки.
- `CHANGELOG.md` — пункт в `## [Unreleased]`.
- Спека `openspec/specs/app-shell/spec.md` обновится при архивации change'а.
- Логика сбора, службы и `MainActivity` не меняются: заставка остаётся оверлеем
  над уже отрисованным главным экраном.
