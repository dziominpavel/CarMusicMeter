# Android emulator profile — CarMusicMeter

Профиль для навыка `android-emulator-verify` и команды `/verify-ui`.
Эмулятор — быстрая проверка UI; поведение штатного плеера, MCU, автозапуска и
SAF всё равно проверяется на Teyes CC3.

## Устройство

- AVD: `fogmap-test` (Android 36, x86_64, Google APIs)
- Package: `com.syu.widget.music`
- Main activity: `com.example.carmusicmeter.MainActivity`

## Сборка и установка

Из корня проекта:

```powershell
build-apk.bat debug install
```

Скрипт собирает debug APK, кладёт его в `dist\CarMusicMeter-debug-latest.apk`
и устанавливает через adb. Не использовать `app\build\outputs\...` как путь
для установки и не заменять `build-apk.bat` произвольным `gradlew assemble`.

Release-сборка (без установки):

```powershell
build-apk.bat release
```

Release подписан другим ключом. Не ставить его поверх debug без удаления
приложения: `adb install -r` может упасть на подписи, а удаление сотрёт данные.

## Запуск

```powershell
adb shell am start -n com.syu.widget.music/com.example.carmusicmeter.MainActivity
```

Или:

```powershell
adb shell monkey -p com.syu.widget.music -c android.intent.category.LAUNCHER 1
```

## Экраны и ключевые состояния

1. **Главный экран, норма** — статус «Идёт», «Сейчас играет», кнопки
   «Экспорт логов» и «Снять срез», строка «Сегодня», вход «Диагностика».
2. **Главный экран без трека** — «Активных медиасессий нет», действия доступны.
3. **Служба остановлена** — статус «Не идёт», баннер «Сбор остановлен»,
   действие «Запустить»; после запуска статус снова «Идёт».
4. **Нет доступа к уведомлениям** — в диагностике «Уведомления: доступа нет»;
   в настройках готовность не 3 из 3.
5. **Диагностика** — секции «Сбор», «Источники», «Текущая сессия»,
   «Последние события»; на телефоне Teyes-строки скрыты.
6. **Настройки** — готовность к машине, хранение, помощь, версия и дата сборки;
   на телефоне строки accessibility нет.
7. **Помощь** — «Проверка в машине» раскрывается в четыре шага.
8. **Экспорт** — диалог с периодом, числом файлов и объёмом; на главном
   экране чипов периода нет.
9. **Снимок** — тост с именем `snapshot-...-manual.json`.
10. **Навигация** — «Назад» и системный back возвращают на главный экран;
    поворот сохраняет текущий экран.
11. **Экран запуска** — при холодном старте круглый медальон с видео-анимацией
    (~1.5 с), пропускается касанием; при возврате из другого приложения и при
    повороте не появляется. На медленном декодере анимация обрывается на 1.8 с —
    это штатное ограничение.

## Размеры экрана

- Телефон (по умолчанию): `1280x2856`, density `480` — примерно 426×952 dp,
  одна колонка.
- Магнитола (имитация): `wm size 1280x720`, `wm density 160` — две колонки,
  главное видно без прокрутки. Диагностика и настройки ограничены по ширине.

```powershell
adb shell wm size 1280x720
adb shell wm density 160
# после проверки:
adb shell wm size reset
adb shell wm density reset
```

## Особенности этого проекта и AVD

- На первом запуске Android 13+ показывает запрос `POST_NOTIFICATIONS`.
  Для проверки состояния «нет доступа» выбирай `Don't allow`; для проверки
  доступа — `Allow`. После переустановки диалог может появиться снова.
- На этом AVD иногда всплывает «System UI isn't responding» — нажимай `Wait`.
- Свайп от нижнего края открывает taskbar/recents; для прокрутки начинай
  свайп выше нижней gesture-зоны.
- Скриншот в инструменте чтения может быть уменьшен. Физический размер — из
  `adb shell wm size`; точные границы кнопок — через `uiautomator dump`.
- Дата сборки в «О приложении» может отставать из-за configuration cache
  Gradle — это не UI-баг.
- Эмулятор не заменяет проверку MediaSession, MCU, автозапуска и SAF на
  реальной магнитоле. Для этого — `docs/HEADUNIT_TEST.md` и выезд в машину.
- Если нужно состояние «музыка играет, источника нет», а медиаплеера на
  эмуляторе нет: логика проверяется unit-тестом `CaptureStatusTest`, а
  визуальное состояние помечается как непокрытое.

## Очистка

```powershell
adb shell wm size reset
adb shell wm density reset
adb shell settings put system font_scale 1.0
adb shell settings put system accelerometer_rotation 1
adb emu kill   # только если эмулятор запускал ты
```
