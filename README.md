# TuneMileage

Тихий сборщик статистики прослушиваний для автомобильной магнитолы **Teyes CC3**
(Android 10) и телефона. Не заменяет штатный плеер: читает активные медиасессии,
медиа-уведомления и громкость, а результаты пишет в локальный журнал.

**Статус: v0 «пробник».** Задача этапа — выяснить, что именно отдаёт штатный плеер
Teyes, и собрать первые реальные данные. Анализ коллекции и отчёты — следующий этап
(см. `docs/ROADMAP.md`).

## Что уже умеет

- показывает активную медиасессию: пакет, трек, исполнитель, альбом, позицию, громкость;
- пишет события в JSONL: старт и конец трека, пропуск, пауза, перемотка, громкость;
- сохраняет полный дамп всех сессий и последних медиа-уведомлений по кнопке;
- экспортирует журнал и снимки в ZIP через системный диалог (работает и на NTFS-флешке);
- переживает выключение зажигания: каждая пачка событий пишется с fsync;
- запускается после загрузки магнитолы и при появлении музыки (можно отключить);
- не имеет разрешения `INTERNET` — данные никуда не уходят.

## Быстрый старт

```bat
build-apk.bat
```

Готовый APK появится в `dist\TuneMileage-release-latest.apk` (и копия в `dist\archive\`).
Для отладочной сборки с читаемыми стектрейсами: `build-apk.bat debug`.

Установка на магнитолу и проверка в машине — `docs/HEADUNIT_TEST.md`.
Для проверки на телефоне: `build-apk.bat debug install` (нужен adb).

## Как это работает

```
штатный плеер
   │  MediaSession / медиа-уведомление
   ▼
NotificationWatchService ──► NotificationCache
   │
MediaWatchService (foreground, опрос 0.5–1 с)
   ├─ MediaSessionProbe ──► ListeningTracker ──► EventLog (JSONL + fsync)
   └─ AudioManager (STREAM_MUSIC) ─┘
                                        │
                                 «Экспорт логов» (SAF)
                                        ▼
                                   ZIP на флешку
                                        ▼
                                анализ на ПК (v1+)
```

Подробности, схема событий и эвристики — `docs/ARCHITECTURE.md`.

## Структура

- `app/src/main/java/com/example/tunemileage/` — код
  - `service/` — foreground-служба и NotificationListener
  - `data/` — трекер, журнал, состояние
  - `probe/` — чтение MediaSession и дамп
  - `diagnostics/` — снимки и crash-лог
  - `ui/` — экран диагностики
- `openspec/specs/` — требования к захвату, громкости и журналу
- `docs/` — архитектура, проверка в машине, план, версионирование
- `scripts/check-version.py` — сверка версии и changelog

## Приватность

Всё хранится в приватной папке приложения на устройстве. Сеть не используется.
Экспорт — только вручную, в выбранный пользователем файл.
